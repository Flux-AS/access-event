# AccessEvent

Инклюзивная платформа мероприятий с акцентом на доступность для людей с нарушениями слуха.

## О проекте
AccessEvent — веб-платформа для организации мероприятий с акцентом на доступность для людей с нарушениями слуха. Организаторы создают мероприятия, участники регистрируются, получают визуальные уведомления и общаются через текстовый чат.

## Возможности
- создание и управление мероприятиями;
- регистрация участников онлайн;
- визуальные уведомления;
- текстовый чат;
- отзывы и оценки.
