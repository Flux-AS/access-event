# Тезисы выступления: AccessEvent

## 0:00-0:30 Проблема и цель

Добрый день! Защищаю проект AccessEvent — веб-платформу мероприятий для людей с нарушениями слуха. Обычные платформы используют звуковые уведомления и голосовой контакт — они бесполезны для этой аудитории. Цель проекта — визуальные уведомления, текстовый чат, цветовая индикация статусов.

## 0:30-1:30 Требования и стейкхолдеры

15 функциональных требований, 8 нефункциональных. Ключевое NFR — WCAG 2.1 AA. Главный стейкхолдер — участник с нарушением слуха. Все требования — в docs/requirements.md.

## 1:30-3:00 Архитектура и БД

Трёхслойная архитектура: HTML/CSS/JS + Jinja2, Flask + SQLAlchemy, PostgreSQL. 7 таблиц. JWT-авторизация. Роли guest, user, organizer, admin. Пароли хешируются, SQL-инъекции отсекает ORM.

## 3:00-5:00 Демонстрация

Показываю: регистрация организатора, создание инклюзивного мероприятия, регистрация участника, чат, визуальное уведомление, цветовой бейдж статуса.

## 5:00-6:00 Тестирование и качество

14 автотестов pytest. 3 бага, 2 исправлены. Все 5 workflow GitHub Actions зелёные.

## 6:00-7:00 Оценка и развитие

SWOT: сильные стороны — инклюзивность, CI/CD. Развитие: push-уведомления, субтитры через ИИ, интеграция с календарями. Спасибо за внимание!
